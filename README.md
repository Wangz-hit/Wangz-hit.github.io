# Zhe Wang — Academic Homepage

Bilingual academic homepage for Zhe Wang, Harbin Institute of Technology.

- `index.html`: English homepage (default)
- `index.zh-CN.html`: 简体中文
- `assets/style.css`: shared responsive styles
- `assets/avatar.webp`: illustrated profile avatar

The website includes published research papers, corresponding code repositories, research interests, education, academic honors, and links to the official HIT faculty pages of Xuyun Fu and Minghang Zhao. Academic contact is provided by email.

## GitHub Pages

Upload the files to the root of the repository used for your personal website (for example, `Wangz-hit.github.io`). In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

The pages are static and use relative URLs. No build step is required.
